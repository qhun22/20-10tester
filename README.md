## Development

This is a static site (HTML/CSS/JS). Node.js is only used as a build tool to compile SCSS to CSS.

```bash
npm install
npm run build   # compiles scss/main.scss -> css/main.css
npm run watch   # rebuilds on change during development
```

## Deployment (Cloudflare Pages)

Connect this repository to Cloudflare Pages:
- Build command: `npm run build`
- Build output directory: `.` (project root)
